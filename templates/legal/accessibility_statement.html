Accessibility Statement & Assistive Standards

InclusiveMatch AI was founded on the fundamental principle that dating and interpersonal connection must be universally accessible. We are committed to removing digital barriers for persons with disabilities, the Deaf community, and individuals with diverse sensory and motor needs.

Our Accessibility Mission

We design and develop our platform with reference to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA and the Rights of Persons with Disabilities Act, 2016 (RPwD Act). We believe in candid disclosure: rather than claiming premature perfection, we document working features, ongoing audits, and remaining accessibility gaps.

1. Assistive Features Implemented

Our engineering team has built several specialized assistive features directly into the core platform:

Live Indian Sign Language (ISL) Recognition

Translates supported Indian Sign Language gestures into text subtitles in real-time during video calls, bridging communication between Deaf and hearing users.

Speech-to-Text (STT) Subtitles

Converts spoken audio into real-time visual captions via the Web Speech API during video calls, ensuring Hard-of-Hearing members can read live dialogue.

Text-to-Speech (TTS) Synthesis

Enables automatic vocalization of recognized sign language gestures or text chat messages for hearing partners using browser speech synthesis.

Multi-Modal Incoming Call Alerts

Incoming calls trigger both an audible ringtone and a high-contrast visual animated modal overlay, accommodating members who are Deaf, Hard-of-Hearing, or working in silent mode.

2. Visual & Sensory Adaptations

  • High Contrast Color Palette: Text elements are styled in Slate 800 (#1e293b) against a Slate 50 background (#f8fafc), achieving a contrast ratio exceeding 7:1 (well above the WCAG AA minimum requirement of 4.5:1).
  • Typography: We employ the highly legible Inter geometric typeface with ample line height (line-height: 1.75) and distinguishable letterforms.
  • Reduced Motion Support: Critical animations respect operating system preferences for reduced motion (@media (prefers-reduced-motion: reduce)).

3. Keyboard Navigation & Focus Standards

InclusiveMatch AI is engineered to be fully operable without a mouse:

  • Skip to Main Content: Every page includes a hidden skip link (<a href="#main-content" class="visually-hidden-focusable">) allowing keyboard users to bypass navigation menus.
  • High-Visibility Focus Indicators: All interactive elements (links, buttons, form inputs, selects) display an unmistakable 3px solid bright yellow focus ring (outline: 3px solid #fde047; outline-offset: 2px;) when tabbed via keyboard.
  • Logical Tab Sequence: Navigation follows a natural top-to-bottom, left-to-right DOM sequence without keyboard traps.

4. Screen Reader Compatibility

  • Semantic HTML5 Landmarks: Pages are structured using appropriate semantic tags: <header>, <nav>, <main>, <article>, and <footer>.
  • Descriptive Form Labels: Form inputs feature explicit <label for="..."> associations and clear validation feedback.
  • Image Alternative Text: User avatars include descriptive alt attributes indicating the profile owner's name.

5. Known Accessibility Gaps & Remediation Roadmap

In accordance with our commitment to transparency, we acknowledge the following areas where improvements are underway:

Area / Component Identified Gap Remediation Status
Video Call Subtitle Timing During rapid speech or signing, live subtitle updates may occasionally cause screen reader verbosity congestion. Implementing ARIA live region rate limiting and quiet modes.
Third-Party Browser Web Speech API Speech-to-Text performance varies across browsers (Chrome/Edge provide full support; some Linux/Firefox browsers require external configurations). Displaying clear browser compatibility badges and fallback text chat.
Comprehensive Screen Reader Testing Manual testing has been conducted primarily on desktop NVDA and Google Chrome TalkBack; comprehensive testing on iOS VoiceOver is in progress. Scheduled for next evaluation phase.
